# Stage 7 native macOS verification

Tested on Apple Silicon with macOS 27.2.1 and Xcode 27.2. The deployment target is macOS 26. The local Web, native desktop and mobile clients can use the same community server. The local fixture on port 8090 ran as a single Compose project.

| Check                     | Observed result                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Native build              | Debug and Release built for arm64. The Release build succeeded with an unusable Java home and the Android SDK environment variable unset. The Mac target has no Gradle phase or Kotlin framework link. The app bundles the WebRTC and native FFI frameworks from the pinned LiveKit Swift SDK.                                                                                                                               |
| Mobile build regression   | The iPhone/iPad target built for the supported arm64 simulator architecture and linked its existing Kotlin framework. The devices stayed powered off.                                                                                                                                                                                                                                                                        |
| Installation and identity | Launched the local development bundle. Connected to the fixture, admitted a guest, reopened the saved server after restart and restored the guest. Existing messages loaded in the channel timeline. The local ad-hoc Release archive unpacked and passed strict recursive code-signature verification.                                                                                                                      |
| Messaging                 | Two separate Swift client instances admitted separate guests on the real server, exchanged a message, observed its edit and deletion via the event stream and restored the author session. The smoke test also checked origin rules, controls in text and Unicode length boundaries.                                                                                                                                         |
| Voice and audio routes    | Joined Lounge muted through the Go signaling endpoint. The sidebar displayed the local participant. LiveKit exposes the system route and the physical device under separate identifiers with identical display names. The native input picker showed one system route and two physical microphones. The output picker showed one system route and the built-in speakers.                                                     |
| Workspace                 | Inspected the split-view window, connection status, language menu and four equal-height voice controls. The push-to-talk switch is in Audio settings. The app keeps the selected chat visible during voice.                                                                                                                                                                                                                  |
| Web and GPUI alignment    | Web passed the repository checks. Playwright joined Lounge, opened Audio settings, enabled and disabled push-to-talk, verified the manual mic button and left the room. React Doctor reported 100/100. On Linux arm64 the GPUI change passed rustfmt, Clippy with warnings denied and the crate tests against the branch's committed manifest and lockfile. Ten tests passed and the opt-in live signaling test was skipped. |

The local archive is a development artifact. Clean-machine Gatekeeper installation, distribution signing and notarization, macOS 26 hardware, physical two-way sound, device switching during an active publication, foreground push-to-talk capture/release, VoiceOver and native staff acceptance remain open. See the [build and Web transition instructions](../../apps/macos/README.md).
