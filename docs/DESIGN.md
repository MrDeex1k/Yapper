# Visual direction

Visual thesis: quiet charcoal surfaces, warm off-white typography and one amber accent give Yapper the feeling of a private listening room.

Content plan: the landing opens with oversized Yapper lettering and a full-width illustrated sound field, followed by independent hosting, the join/talk workflow, and a final install CTA. No stock statistics or pretend product screenshots.

Interaction thesis: stagger the brand entrance; let the sound field shift gently with scroll; use short focus/hover transitions and clear connection-state changes. Respect reduced motion throughout.

The application starts with the working surface: instance navigation, channel navigation, conversation, and a persistent connection/audio bar. Use dividers and typography rather than card grids. Forms have explicit labels and live feedback. Empty states are honest: never fabricate people, messages or server health.
